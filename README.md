# QT Creator Mobile

IDE Android on-device para desenvolvimento nativo multi-linguagem (C, C++, Java, Kotlin), voltada para apps pesados (jogos, animacao, desenho) compilados 100% no celular, sem depender de laptop.

Suporte nativo completo a C e C++, Java, e Kotlin com Jetpack Compose + Material3 (plugin compilador do Compose incluido), alem de ponte entre as linguagens via NDK/JNI.

Projeto novo e independente. Referencias como o CodeAssist (Tyron) servem apenas como estudo conceitual de IDEs mobile, nao como base de codigo.

Veja `docs/ARCHITECTURE.md` para o desenho tecnico completo e o estado atual de cada modulo.
